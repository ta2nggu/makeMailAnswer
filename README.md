# AI Mail Assistant (AI 메일 답장 작성 어시스턴트)

본 프로그램은 받은 이메일 목록을 읽어와 Google Gemini AI를 통해 상황에 맞는 정중한 비즈니스 답장 초안을 자동으로 생성하고, SMTP 서버를 이용해 즉시 전송할 수 있도록 돕는 웹 어플리케이션입니다.

---

## 🚀 시작하기 (실행 방법)

### 1. 사전 요구 사항
* **Node.js** (v18 이상 권장)가 설치되어 있어야 합니다.

### 2. 패키지 설치
프로젝트 루트 디렉토리에서 아래 명령어를 실행하여 필요한 의존성 라이브러리를 설치합니다.
```bash
npm install
```

### 3. 환경 변수 설정 (`.env`)
프로젝트 루트 폴더에 `.env` 파일을 생성하고(혹은 기존 파일 수정), 메일 서버 정보와 Gemini API Key를 입력합니다.
```env
# Mail Server Credentials
MAIL_USER=your_email@domain.com
MAIL_PASSWORD=your_email_password

# KT Biz Office Mail Server Settings (POP3 & SMTP)
POP3_HOST=jmp.ktbizoffice.com
POP3_PORT=995
SMTP_HOST=jmp.ktbizoffice.com
SMTP_PORT=587

# Google Gemini API Key
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.1-flash-lite
```

### 4. 프로그램 실행
아래 명령어를 입력하여 로컬 개발 서버를 기동합니다.
```bash
npm run dev
# 또는
npm start
```
서버가 시작되면 웹 브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속할 수 있습니다.

## 💡 사용 방법

1. **메일 불러오기 & 동기화**
   * 웹 페이지에 처음 진입하면 캐싱된 최근 메일 목록이 즉시 표시됩니다.
   * 우측 상단의 **새로고침(↻)** 아이콘을 클릭하면 메일 서버(POP3)를 조회하여 최신 메일을 즉시 동기화합니다.
2. **처음 보내는 새 메일 작성 (신규 발송)**
   * 좌측 사이드바 상단의 **[+ 새 메일 작성]** 버튼 또는 초기 화면의 **[새 메일 작성하기]** 버튼을 클릭합니다.
   * **수신자 정보/호칭(선택)**, **메일 주제(선택)**, **전달할 핵심 용건/내용(필수)**을 입력합니다.
   * **[AI로 정중한 새 메일 생성]** 버튼을 누르면 Gemini AI가 정중한 비즈니스 톤앤매너와 로젠 정보전략팀 서명 규격을 갖춘 신규 메일 초안을 생성합니다.
   * 받는 사람(To), 참조(Cc), 제목, 본문을 확인 및 자유롭게 수정한 뒤 **[이 메일 바로 발송하기 (SMTP)]** 버튼을 누르면 즉시 발송됩니다.
3. **실시간 메일 검색**
   * 좌측 사이드바 상단의 검색창에 검색어(메일 제목 또는 발신자 이름/주소)를 입력합니다.
   * 실시간 디바운스 검색(입력 종료 후 400ms 대기 후 검색)이 작동하여 빠르게 원하는 메일을 찾을 수 있습니다.
   * 검색어 입력 시 생기는 우측 **X** 버튼을 누르면 검색 결과를 바로 초기화할 수 있습니다.
4. **메일 Q&A 챗 (문맥 및 내용 이해)**
   * 이메일의 내용이 난해하거나 문맥 파악이 안 될 때, 우측 상단 탭에서 **[메일 Q&A 챗]**을 선택합니다.
   * 채팅 창에 궁금한 내용을 자연어로 질문하면(예: *“이 메일의 핵심 요구사항이 뭐야?”*, *“여기서 말하는 용어가 무슨 뜻이야?”*), AI가 해당 메일의 전체 문맥을 이해하고 대화 형식으로 상세히 답변해 줍니다.
   * 대화 기록(Chat History)이 누적 관리되므로 꼬리 질문이나 추가 설명 요청이 가능합니다. (새로운 메일을 선택하면 대화 내용은 자동으로 리셋됩니다.)
5. **AI 답장 생성 & 회신 (받은 메일)**
   * 사서함 목록에서 메일을 선택한 후 **[답장 작성]** 탭에서 **답장하고자 하는 요점**을 간단히 작성합니다. (예: *“내일 오후 3시 미팅 제안 수락한다고 전해줘”*)
   * **[AI로 정중한 답장 생성]** 버튼을 누르면 Gemini AI가 비즈니스 격식에 맞는 공손한 한국어 답장 초안을 작성합니다.
   * **[이 메일 바로 답장하기]** 버튼을 누르면 설정된 SMTP 서버를 통해 수신인 및 참조자(CC)에게 이메일이 실제 발송됩니다.

## 🛠️ 핵심 동작 메커니즘

### 1. 실시간 검색 및 증분 캐시 연동 (High-Performance Caching)
* **POP3의 한계 극복**: POP3 프로토콜은 메일 서버 측 검색(SEARCH) 기능을 지원하지 않아 매번 대량의 메일을 동기 조회하면 속도가 급격히 저하됩니다.
* **UIDL 기반 헤더 캐싱**: `UIDL` 명령어로 메일 고유 식별자(UID) 목록을 1초 이내에 가져와 로컬 캐시 파일(`mail_cache.json`)과 비교합니다.
* **증분 동기화**: 이미 캐싱된 메일의 상세 헤더(Subject, From, Date)는 스킵하고, 캐시에 없는 신규 메일 헤더만 선택 다운로드하여 통신 병목을 없앴습니다.
* **백그라운드 스레드 분할 동기화 (Background Sync)**: 
  * 최초 구동 시 지연을 방지하기 위해 최신 50개 메일을 먼저 빠르게 긁어와 사용자 화면을 보여줍니다.
  * 나머지 450개 메일(기본 최대 500개 유지)은 백그라운드 큐를 통해 10개씩 조용히 다운로드 및 캐싱합니다.
* **POP3 세션 직렬화 (Mutex Lock)**:
  * POP3 계정은 다중 접속(Concurrent Connection) 시 계정 잠금 오류(`mailbox locked`)가 발생합니다.
  * 내부 Promise 체이닝 기반 `runWithPop3Lock` 뮤텍스를 설계하여 백그라운드 동기화 도중에도 사용자의 본문 읽기 요청이 막힘 없이 최적화 처리됩니다.

### 2. Gemini AI 비즈니스 톤앤매너 프롬프팅
* 사용자 요점 지시사항과 원본 메일 헤더/본문을 정밀 결합하여 Gemini AI 모델에게 정교한 비즈니스 템플릿 프롬프트를 주입합니다.
* 비즈니스 한글 톤앤매너를 강제하고 맞춤법 교정 및 자연스러운 단어 선택을 지원합니다.
* 지정된 책임 서명 템플릿(안녕하세요, 로젠 정보전략팀 김태영 책임입니다...)을 결합한 일관성 있는 비즈니스 포맷을 제공합니다.

### 3. Iframe HTML 격리화
* 수신 메일 본문의 HTML 스타일이 메인 어플리케이션 UI 스타일을 망가뜨리지 않도록, 빈 Iframe 내부에 DOM 도큐먼트를 동적으로 새로 써내려가는 방식으로 렌더링 영역을 완벽하게 격리 처리했습니다.

### 4. 메일 내용 분석 및 대화형 Q&A (Multi-turn Chat)
* 사용자가 질문하면 API 서버는 **현재 선택한 메일의 전문**을 `systemInstruction` 형태로 Gemini AI 모델에 강제로 주입합니다.
* 사용자가 입력한 메시지와 이전 대화 내역(`history`)을 함께 전달하여, 이메일 내용에 극도로 국한된 정확하고 안전한 맥락 정보(Context) 하에서 대화를 이어나갈 수 있도록 유도합니다.
* 메일을 새로 선택할 때마다 클라이언트와 서버 측의 대화 세션 컨텍스트가 완전 초기화되어 다른 메일과 내용이 섞이지 않도록 격리했습니다.

### 5. 대화창 스크롤 및 레이아웃 최적화 (Chat Layout Optimization)
* 대화 내용이 길어질 때 입력창이 화면 아래로 밀려나거나 내용이 보이지 않는 문제를 방지하기 위해, 웹 페이지 전체 높이(`100vh`)와 메인 컨텐츠 영역의 레이아웃 크기를 제한(`min-height: 0; overflow: hidden;`)하여 화면 바깥으로 요소가 확장되지 않도록 고정했습니다.
* Q&A 대화창 내에 독립적인 스크롤 영역(`overflow-y: auto; max-height: 100%;`)을 구성하고 Firefox 대응 스크롤 스타일을 제공하여, 메시지가 많아져도 항상 하단 입력창을 유지한 채 대화 내역만 스크롤하여 확인할 수 있게 개선했습니다.
